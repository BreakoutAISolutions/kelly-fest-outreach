# Kelly Fest Outreach

Mobile first approval deck for The Canna Joint and Save Hemp Bev Fest.

## What Kelly can do

Review outreach ideas by group.

Edit group templates and individual messages.

Tap Yes or No on each target.

Copy a final summary of approved targets and their final DMs.

Choices and edits persist in the browser using localStorage.

## What this site does not do

This site does not send Instagram DMs.

It does not log into Instagram.

It does not scrape Instagram.

It does not use the Instagram Messaging API.

It does not sync with a CRM.

It does not contain authentication or a database.

Approved outreach should be sent manually from @the.cannajoint.

Media outreach is owned by Aria. Kelly should not pitch or negotiate media. If media replies to Kelly, she should screenshot the reply and send it to Aria.

## Required placeholders

Before real outreach is sent, fill in:

[DATE]

[TICKET]

## Operating rules

21+ only.

No WSSU or A&T student pages.

No family accounts.

One follow up after 4 days. Then stop.

Do not offer cash unless the organizer approves it.

Kelly does not pitch media. Aria handles media.
